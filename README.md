# Zquiz · 期末周刷题

把题目粘进来就能刷。**纯前端、零依赖、零构建、无需注册**,数据只存在你自己的浏览器里。

**在线用**:<https://zdx1717.github.io/zquiz/>(手机浏览器打开,建议「添加到主屏幕」当 App 用)

## 能做什么

**导入**
- 题目**不必先整理格式**:字段式 / 编号式 / 单行混排 / 判断题自动识别,文末答案表也能按题号回填
- 两条路进来:**粘贴文字**(Word / 网页 / 微信复制都行)或**选文件**(Word / PDF / txt;PDF 是文字版才读得出)
- **先预览再入库**:逐题勾选、直接改题干与答案、自动查重,缺答案的题进「待补」不会丢
- **AI 两件事**(自带 Key,只存本机):「AI 整理输入框」只理顺格式、**绝不替你编答案**;「AI 补答案·解析」只补空白,补上的永久标 🤖

**刷题**
- 逐题模式(每题即判)/ 套题模式(整卷交卷再判);答对自动翻页的**智能切题**
- **答题卡**点进度展开,一格一题,点题号直达
- 题源可选**题库 / 错题本 / 收藏夹**,答错与未作答自动进错题本(连对 N 次可自动移出)

**题库管理**
- 多题库:创建 / 重命名 / 编辑 / 删除 / 导入 / 导出 / 一键去重;可视化编辑器逐题改
- 两层撤销:会话内 `⌘/Ctrl+Z` 撤销栈 + 跨会话**版本快照**(破坏性操作前自动存)+ 回收站

**全局**
- 标题栏一个图标键切主题(自动 / 亮 / 暗);可装到主屏全屏用;**数据不上传任何服务器**

## 快速上手

1. 打开在线地址(本地要起静态服务:`python3 -m http.server`;ES Module 不支持 `file://` 直开)
2. 首页粘贴题目或选文件 → 「解析并预览」→ 检查后导入题库
3. 刷题页选题源与模式 → 开始刷题

## 题库格式

**不用整理格式,直接粘。** 认这几种:`题目：/A：/答案：`(字段式)、`1. 题干 + A. 选项 + 答案：B`(编号式)、
`1. 题干 A.xx B.xx 答案：B`(单行混排)、答案写 `对/错/√/×`(判断题)。
答案可在题内或**文末集中答案表**(`1.B` / `1-5 ABBDA`);双行选项、全半角逗号、选项折行等脏格式都能容错。

> 📖 完整格式、可选字段(`解析：` `A解释：` `类型：`)与示例见 [`FORMAT.md`](FORMAT.md)

## 数据与隐私

- 题库 / 错题本 / 收藏只存在浏览器 LocalStorage,**不上传任何服务器**
- 清浏览器数据会连题库一起清掉 —— 重要题库请用「导出题库」定期备份;换设备就导出再导入

## 技术

原生 HTML/CSS/ES Modules,**运行时零依赖、零构建**;存储用 LocalStorage;托管 GitHub Pages。
测试:`npm test`(Node 内置 runner);改样式前先读 [`DESIGN.md`](DESIGN.md)。
模块依赖方向 `main → 业务模块 → parser/storage/state`,`parser/state` 零依赖、禁止反向引用。
