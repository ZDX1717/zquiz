# Zquiz · 期末周刷题

把任意格式的题目粘进来就能刷。纯前端、**零依赖、零构建、无需注册**,数据只存在你自己的浏览器里。

**在线使用**:<https://zdx1717.github.io/zquiz/>(手机浏览器打开,建议"添加到主屏幕"当 App 用)

## 能做什么

**导入(首页)**
- 多格式自动识别:字段式 / 编号式 / 单行混排 / 判断题,**不必事先整理格式**;输入框右上角「?」随时查格式说明
- **两条路导入**:① 粘贴文字(Word / PDF / 网页 / 微信复制过来都行,按段落与表格结构读取)② 选文件(`Word` / `PDF` / `txt`,文字读进输入框可再改);PDF 与老版 `.doc` 会给出专门提示(附 AI 提取提示词或转格式)
- 文末集中答案表按题号自动回填
- **导入预览向导**:解析结果先预览再入库 —— 逐题勾选、直接改题干与答案、自动查重、
  缺答案/选项不足等警告提示,确认后才写进题库
- **AI 双模式**(自带 Key,只存本机):
  - 🤖 **AI 格式整理(不改内容)**:只把格式理顺,**绝不替你编答案**(材料里没答案就留空)
  - ✍️ **AI 补答案·解析**:**只给缺答案/缺解析的题**补,已有的一律不动;补上的答案永久标 🤖、导出也注明来源
  - 解析不出题目时,首页会自动展开**「AI 整理成标准格式」**并给出两条路(复制提示词给聊天 AI / 一键整理),两条都在,按配没配 Key 分主次

**刷题(刷题页)**
- **逐题模式**:每题立即出答案,边刷边学;**套题模式**:整卷作答、可回改,交卷后统一判分并逐题回顾
- **答题卡**:点进度即可展开,一格一题看清答对/答错/未答,**点题号直达任意一题**
- **智能切题**:答对自动翻到下一题,答错停在本题看解析
- 题源可选**题库 / 错题本 / 收藏夹**,范围按题库与题型收窄
- 结束后给正确率与逐题回顾,支持「只看错题」

**管理(题库页)**
- 多题库:创建 / 重命名 / 编辑 / 删除 / 导入 / 导出 / 一键去重
- **可视化编辑器**:逐题改题干、题型、选项、答案、解析,增删题目与选项
- **错题本闭环**:答错与未作答的题自动归档;可配置"答对 1/2/3 次自动移出"或关闭
- **收藏夹**:刷题时一键 ☆ 收藏,汇总成册
- 错题卡与收藏卡是**同一套设计**:题型 / 收藏 / 删除 在题干上方一行,答案默认遮挡(主动回忆)
- **题库卡配色**:给每个库挑一个低饱和颜色(蓝/绿/红/琥珀/青),默认与其他卡片一致的灰
- **撤销分两层**:会话内「↩︎ 撤销栈」(⌘/Ctrl+Z 与 Shift+⌘/Ctrl+Z 重做,深度 50,不落盘)+ 跨会话**库级版本快照**(每库 5 版 / 全站 20 版,导入、去重、批量删、覆盖导入、恢复前自动存一版);另有回收站(上限 10 条)

**全局**
- 三个分区:**首页 = 导入、刷题 = 做题、题库 = 管理**
- 暗色模式一键切换(自动 / 亮 / 暗 循环,存本机;标题栏一个简约图标键)、手机全出血布局
- **可装到手机主屏**:带自己的图标、点开**全屏无地址栏**(PWA manifest + 全套图标)
- 数据只在本机:刷新不丢,**不上传任何服务器**;可导出为 txt 备份迁移

## 快速上手

1. 打开在线地址(或本地起静态服务:`python3 -m http.server`,ES Module 不支持 `file://` 直开)
2. 首页把题目粘进导入框(或选 txt / docx 文件)→ 解析并预览 → 检查无误后选择题库导入
3. 刷题页选题源与模式 → 开始刷题
4. 错的题自动进错题本,考前来一轮错题回顾

## 题库格式(重点)

**不用整理格式,直接粘**。解析器认这几种:

| 格式 | 样子 |
|---|---|
| 字段式 | `题目：` `A：` `答案：` |
| 编号式 | `1. 题干` / `A. 选项` / `答案：B` |
| 单行混排 | `1. 题干 A.xx B.xx D.xx 答案：B` |
| 判断题 | 答案写 `对/错/√/×/正确/错误`(选项会自动配好) |

- **答案**可写在题内(`答案：B`、题末括号 `（B）`),也可用**文末集中答案表**(`1.B` / `1-5 ABBDA` / `1.对`)
- **可选字段**:`题目解释：`(作答时可见)、`解析：`(判分后可见)、`A解释：`(选项解释)、`类型：`
- **没答案也能导入**:进"待补"池,刷题时自动跳过,补完答案转正
- **脏格式能容错**:双行选项、全半角逗号/空格分隔、选项折行归并、空括号清理、按"题干+选项"自动查重

> 📖 **完整格式说明、字段清单与可照抄示例见 [`FORMAT.md`](FORMAT.md)**
> (PDF / 扫描件怎么办、各写法细节都在那里)

## 文件说明

```
index.html            主页面（首页=导入 / 刷题 / 题库=管理 三个分区）
styles.css            样式（设计令牌集中在 :root）
DESIGN.md             视觉宪法：令牌 / 字号 / 间距 / 交互规范（改样式前必读）
FORMAT.md             题库格式详解（README 只留重点）
src/
  main.js             应用装配入口：事件绑定 + 页面调度
  state.js            共享状态（全站唯一可变数据容器，零依赖）
  parser.js           纯函数解析核心（多格式解析 / 答案规范化 / 判分指纹，零依赖）
  storage.js          存储层（唯一触碰 localStorage 的模块，含损坏降级）
  quiz.js             刷题（逐题 / 套题 / 判分 / 答题卡 / 逐题回顾）
  bank.js             题库管理 / 导入预览 / 题库编辑器 / 导出 / 库卡内嵌的错题与收藏面板
  errorbook.js        错题闭环（独立列表渲染为兼容保留，列表已并入库卡）
  favorites.js        收藏数据与切换（列表渲染同上）
  docx.js             docx 文件抽取（零依赖 zip + XML → 纯文本）
  dom.js              通用 DOM 工具（模态框开关 / 文件下载）
tests/                Node 内置 test runner 回归套件（17 个文件 / 236 个用例）
.github/workflows/    CI：push/PR 自动回归
```

模块依赖方向:`main → 业务模块 → parser/storage/state`,`parser/state` 零依赖,禁止反向引用。

## 技术栈与运行

- HTML5 / CSS3 / 原生 JavaScript (ES6+),**运行时零依赖、零构建**;ES Modules 多模块架构
- 存储用 LocalStorage;托管在 GitHub Pages
- 本地开发:起个静态服务即可(见「快速上手」);测试 `npm test`
- 支持所有现代浏览器(Chrome / Firefox / Safari / Edge)

## 数据与隐私

- 所有数据(题库、错题本、收藏)只存在浏览器的 LocalStorage,**不上传任何服务器**
- 清除浏览器数据会连同题库一起清掉 —— 重要题库请定期用「导出题库」备份
- 换设备 / 换浏览器:先导出、在新设备导入即可迁移
- 隐私模式或清缓存可能清空数据,请及时备份

## 版本规则

开发阶段用 **0.y.z**:每个 **`y` = 一个功能**(一个独立可验收的能力),**`z` = 同一个 y 阶段里的 bug 修与小调整**—— 攒一批再发,不为每次改动打 tag;`1.0.0` 留给正式稳定版。

判据(满足其一即算新 `y`,否则进 `z`):① 新增一类用户能感知的能力;② 新增/变更数据字段或存储格式;③ 新增或改动一个页面或主要交互流程。
